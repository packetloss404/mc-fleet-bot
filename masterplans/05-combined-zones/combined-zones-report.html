The decision

The original `(2250,-300)`, 90-degree transform failed because Houston, the public shaft, and the summit met water, while only 35.60% of the proposed Empty Eight roof had eight dry solid blocks of cover. The program survives; that physical setout does not.

Adopted layout. Keep Ravensreach as the canonical Old Town. Keep Gateway Approach as a separate current-world adapter. Put the normalized Combined Complex at `(2048,-328)` with no top-down rotation, so Houston faces the arrival and the mountain extends north.

Delivery and controls

  1. Phase 0 — complete, PASS. Snapshots, chunk coverage, raster, candidate search, terrain/structure censuses, terminal cover, and sampled rail profile are sealed.
  2. Phase 1 — civil and interfaces. Freeze road/rail profiles, C01 structural checks, bridges/tunnels, hydrology, relic buffers, Z02 stops, subway shell, egress, ownership, and rollback boundaries.
  3. Phase 2 — deep shells. Build Empty Eight, shaft, SubTropolis, service/contact route, and Cheyenne shell before surface loads.
  4. Phase 3 — surface framework. Build the mountain around protected relic voids, Gateway Approach, Grand Avenue, Houston, stops, and summit switchbacks.
  5. Phase 4 — fit-out. Complete the terminal mall/platforms and internal city, industrial, secure, and summit programs.
  6. Phase 5 — commissioning. Bidirectional route tests, rail/minecart tests, doors, entities, rollback, immutable post snapshot, database import, and matched media.

Release rules

  • One canonical compiler and one owner per physical cell.
  • Generated structures and accepted features are default-deny.
  • Every physical package needs a fresh immutable source, exact guarded forward and rollback operations, strict-noop preflight, live clearance, and post-state acceptance.
  • Phase 0 PASS authorizes detailed design only. No world edits are authorized by this report.
