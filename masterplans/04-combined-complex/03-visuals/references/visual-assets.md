## How to read this catalog

Each category lists every file by `index.jpg` in its folder. Files are described based on direct visual inspection of the downloaded image. File size is shown so the renderer can quickly skip tiny thumbnails when picking hero shots. Source URLs point to the original page; licenses are inferred from the source (Wikipedia / Commons → public-domain or CC; tourism boards → usually CC-BY; news sites → editorial use).

**Hero picks** (the 5 most valuable assets overall) are listed at the end with their category tags.

## Top 5 Most Valuable Assets

These are the five images that, if only five could be used, would best represent the combined complex.

1. **`combined-civilian-military/4.jpg` — 13.9 MB Sassi di Matera from the cave**
   *Why:* It is **the single best visual for the integration concept** — civilian architecture built into a ravine, with the rock-and-cave material reading exactly like the SubTropolis-and-Cheyenne composite. Massive resolution means it works at any size from thumbnail to full spread.

2. **`mountain-range-ravine/4.jpg` — 2.2 MB geological-strata cliff face with person for scale**
   *Why:* It shows the **two-rock-types** concept (sandstone, shale, siltstone layers) better than any other image. A 2.2 MB JPEG means the renderer can crop tight for a cross-section diagram. Critical because the project brief specifically calls out visible rock-type variation in the mountain range.

3. **`cheyenne-mountain/0.jpg` — 3.1 MB NORAD command center interior**
   *Why:* This is the **mood-defining image** for the Cheyenne side. The backlit map displays, warning labels, and low-key lighting set the tone for the entire military chapter in a way no exterior shot can. 3.1 MB is plenty for full-page use.

4. **`ravine-gorge/1.jpg` — 1.8 MB Verzasca Valley with the old stone arch bridge**
   *Why:* The **scale, material, and engineered-crossing** composition is exactly what the inter-site service tunnel through the ravine needs. The stone bridge stands in for the tunnel crossing. Visible metamorphic rock strata in the gorge walls support the "rock type variation" brief.

5. **`city-in-valley/6.jpg` — 1.3 MB Zermatt at night with the Matterhorn**
   *Why:* The brief calls out "the city in the valley" as one of the two most important visuals. This is the **best night version** — glowing windows against the dark mountain show how a real city reads in a valley. Pairs naturally with `city-in-valley/0.jpg` (the daytime Zermatt area shot) for a day/night cover pair.

Honorable mention: **`subtropolis/2.jpg`** (the abandoned mine, 4.7 MB) is the most natural pick for the SubTropolis cover, and **`minecraft-refs/0.jpg`** (MorchWORX) is the best preview of what the actual Minecraft build will look like.

## Gaps

Things the next search pass should try to fill:

1. **Gotthard / Lötschberg interior shots** — the existing `service-tunnel` set is mostly exteriors. An interior shot of a modern high-speed rail tunnel (smooth walls, lighting, dual-bore) would be a strong addition.
2. **Real mountain-cliff elevator** — the Bürgenstock Hammetschwand Lift, the Gateway Arch tram, or a similar cliff-face elevator. The current `vertical-transport` set is mostly cable cars and a city U-Bahn lift.
3. **Houston Tunnel System interior** — the actual downtown Houston tunnel concourse, ideally with the characteristic "TUNNEL" signage or the red-brick tunnel walls. The current `houston-tunnels/0.jpg` (PCC Market) is a strong stand-in but not the real thing.
4. **Aerial view of an actual mountain site with both hard-rock and sedimentary terrain visible** — what `mountain-range-ravine/4.jpg` does, but in landscape rather than portrait.
5. **High-resolution concentric defense diagram** — `defense-depth/6.jpg` (the historical castle engraving) is the best of the set, but a modern layered-defense cutaway (like a real magazine fort or a Cold War bunker cutaway) would be more useful.
6. **Cheyenne Mountain exterior / aerial** — the current `cheyenne-mountain` set is dominated by interior shots. One clear exterior showing the mountain itself with the portal is worth having.
7. **SubTropolis real interior** — the abandoned mine in `subtropolis/2.jpg` is great, but a real SubTropolis.com marketing shot of a fitted-out tenant space would be a useful contrast.
8. **Editorial photos of the actual Cheyenne Mountain / SubTropolis / Houston Tunnel** — the current set is built from generic image searches. Direct-source photos from the operators would be more authoritative.
