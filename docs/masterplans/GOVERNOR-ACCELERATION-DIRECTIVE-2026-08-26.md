# Governor acceleration directive — 26 August 2026

The Governor has delegated build decisions and all required named owner,
counterpart, and signature roles to the implementation team for the Master
Plan.

## Effective immediately

- A named role in an acceptance contract is an internal accountable build role,
  not a request for a separate person's approval.
- Independent, disjoint scopes must run in parallel. A held water, gravity,
  egress, or owner interface may stop only its exact interaction set.
- Historical holds, duplicate surveys, and publication/media work cannot be
  reintroduced as serial prerequisites where a current ledger or source-bound
  compiler has superseded them.
- A signature gate must report the missing *technical* input directly. It may
  not wait for a ceremonial counterpart response.
- Water or lava encountered by a scoped build is containment work: compile a
  finite sealed/supported flow-ordered liner or plug, with exact inverse and
  receiver/overflow handling, rather than recording a generic fluid hold.
  An unbounded observed component first needs a finite containment boundary;
  unobserved fluid state must never be guessed.

## Still non-negotiable

Every physical release must retain the scoped hard-safety kernel: fresh
immutable source; exact canonical source, target, and rollback states; exact
inverse; contained fluid/gravity/receiver behavior; protected-core,
container/block-entity, and live-entity treatment; strict-noop parser and
source preflights; journaled execution; fresh immutable post state;
rollback-poststate proof; and functional route/mechanism verification.

The directive accelerates responsible construction. It does not authorize
guessing at unknown world state or calling a design, map, or partial release
complete.
