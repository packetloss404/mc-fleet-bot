Supplements `HANDOFF.md`, which covers the platform and the 2026-07-25 audit. This
one covers the world-building session that relocated the stadium and, more usefully,

Start here: **`python3 scripts/build_status.py`**. It is the source of truth. The W4

## 1. The finding that matters most

**Placement and traversability are different properties, and we had only ever
checked placement.**

`verify_ops.py` samples an ops file against the world and reports whether each block
landed. It scored the Moot Hall descent **BUILT 5/5**. Every block it sampled genuinely
existed. The shaft was still unusable: a corridor ceiling sealed it at y46, the Sanctum
dome cap sealed it again at y51, and the bottom five blocks had no ladder.

That is not an edge case. Sweeping every space built this session found **three
completely sealed builds and three partly sealed ones**, including a 6,000-seat theatre
that nobody can enter and a members' lounge with no door. All of them "built fine".

Two corollaries, both now enforced in `builds/manifest.yaml`:

- **Downward reachability is meaningless.** A player falls any distance but climbs one
  block, so a one-way check passes on a hole in the floor. *Every* basement in this
  town passed that way. Use `both_ways: true`.
- **Assert against measured cells, never a design doc.** Nearly every false failure in
  the first run of the checklist was a target sitting one or two blocks inside a floor
  slab, a bookshelf or a stage deck. Moot Hall B2 went from `BLOCKED` to `OPEN 99%` on
  *unchanged geometry* once I stopped guessing coordinates. Prefer
  `reachability.mjs --box`, which enumerates a room's own standable cells and reports
  what fraction you can reach — it needs no lucky guess.

## 3. Build tooling — read this before building anything

### 3.1 Use RCON, not the bot

`build_runner.py` drives an opped mineflayer bot through WorldEdit because a WorldEdit
selection belongs to a *player* and the console has none. That is **~1.5 s per op** —
three chat round-trips plus a reply poll.

`scripts/rcon_runner.py` uses vanilla `/fill` instead: **0.002 s per command**. The
9,500-op Westlight programme went from a projected four hours to **19 seconds**.

Three things it handles because all three fail silently:

- `/fill` refuses unloaded chunks with `That position is not loaded`. The bots never
  move (we place by coordinate), so nothing at a remote site is loaded. It force-loads
  the bounding box and restores any of the operator's ~281 pinned chunks that its own
  release takes with it.
- `/fill` caps at 32768 blocks. Bigger boxes are split.
- `/fill` has no random patterns. **Lay geometry down flat and scatter accents
  afterwards in a few big WorldEdit `//replace` passes** — 1,540 per-row mix ops cost
  ~38 min through a bot; four `//replace` cost seconds.

### 3.2 Order of operations: carve vertical shafts LAST

Three separate corridor ceilings each re-sealed the Moot Hall shaft during a single
repair. Any op that lays a floor or ceiling across a shaft's footprint will close it.
Put the shaft carve at the end of the file and it cannot be undone by its own build.

### 3.3 Never use a player-relative WorldEdit command

`//cyl`, `//sphere`, `//pyramid` are centred on the player, and the bot **falls**
between the `/tp` and the command landing. Measured: a cylinder aimed at y=100 landed
at y=98; one aimed at y=104 landed at y=101. Spectator mode does not fix it. Rasterise
the shape in Python and emit absolute-coordinate boxes.

### 3.4 Doors need two ops

A door is two blocks with *different* block states. Setting a 2-tall selection to a
door id writes two `half=lower` halves, which is invalid and pops off on load. **Every
door placed this session vanished this way** — 29 of them, across the library, the
canal houses, the Grange Hall, three cottages and the penthouse. All four generators
now carry a `door()` helper; use it.

### 3.5 This server renamed `chain` to `iron_chain`

`setblock … chain`, `fill … chain`, `//set chain` and `//set minecraft:chain` all
reject the legacy id. The valid 1.21.11 registry name is `minecraft:iron_chain`, which
works directly through `/fill`; the 59 theatre rigging placements are now built and
sampled 8/8, and the 49 previously absent Sanctum placements were restored through
`fix15_sanctum_rigging.txt`. `rcon_runner.py` still blocks the legacy id so old ops
cannot lose blocks silently. Also `smooth_basalt_slab` **does not exist** —
smooth_basalt has no slab variant, and an LLM design proposed it.

### 3.6 Never wait on a `pgrep` that matches your own command line

A sequencer waited on `pgrep -f "buildops/ch2_bowl"` — which matched *itself*. It waited
forever, and **seven ops files were never run**: the whole concert-hall fit-out and the
entire members' club. The runner logs looked healthy the whole time. Nobody noticed for
hours. Three of those waiters were still spinning at the end of this session, one of
them armed to build a club into a field that had since been demolished.
